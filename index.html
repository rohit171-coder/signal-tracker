Google Sheets Sync
Pull from Google Sheets (read, free, no login)
  1. Open your Google Sheet → File → Share → Publish to web
  2. Select the correct tab, choose CSV, click Publish
  3. Copy the URL and paste below — auto-refreshes every 15 min
Push to Google Sheets (write-back via Apps Script)
  1. In your sheet open Extensions → Apps Script
  2. Paste the template below, click Deploy → New deployment as Web App
  3. Set Who has access to Anyone, copy the URL
